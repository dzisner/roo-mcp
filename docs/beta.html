Connect Roo to Claude.

Two things to paste — a URL and your API key — and you can ask Claude to make shortlinks, add QR codes, or fire off webhooks in plain English.

Before you start, you'll need

  • An account on app.roo.bz — the free "Hop" plan works fine.
  • Claude Code (the terminal tool) or Claude Desktop (the Mac/Windows app).

Get your Roo API key

Sign into app.roo.bz. Click your profile → Account Settings → Api Keys tab. Press the copy button next to your key.

Keep it private Treat this like a password. Don't paste it in a chat, an email, or a support ticket. You'll paste it once in Step 2 and Claude keeps it on your machine from then on.

Connect Claude to Roo

Pick the Claude you use:

Open your terminal and run this. Replace PASTE_YOUR_KEY_HERE with the key you copied in Step 1.

claude mcp add --transport http roo \
  https://mcp.roo.bz/mcp \
  --header "x-api-key: PASTE_YOUR_KEY_HERE"

Then verify it's connected:

claude mcp list

You should see roo in the list with a Connected status.

Don't have Claude Code yet? Install it with the one-liner at docs.claude.com/en/docs/claude-code/overview, then come back.

Inside Claude Desktop:

  1. Click your profile picture (bottom-left) → Settings → Connectors.
  2. Scroll to the bottom and click Add custom connector.
  3. Fill in these fields:
NameRoo
Remote MCP server URLhttps://mcp.roo.bz/mcp
Sign-inNo sign-in
Request headers → Namex-api-key
Request headers → Value(paste your key)
  1. Click Add (or Save). You're done.
Don't see "Request headers"? That section is in beta rollout and some accounts don't have it yet. If it's missing, use the longer local-install guide for now — same end result, a few more steps.

Try it out

Start a new chat and try any of these:

  • Check my Roo account.
  • Make a Roo shortlink for https://example.com/my-page.
  • Create a shortlink to my landing page and generate a QR code for it too.
  • Show me my last 5 Roo shortlinks.

Claude will call Roo behind the scenes and show you the new short URL, QR image, or click counts right in the chat.

Something didn't work?

Claude doesn't seem to know about Roo.

Start a new chat (the connection registers at session start). On Claude Desktop, if that doesn't fix it, fully quit the app (not just close the window) and re-open.

I get "Roo API key is missing or invalid."

The key doesn't match one Roo recognizes. Go back to app.roo.bz → Account Settings → Api Keys, copy the key fresh (or generate a new one if you're not sure), and set it again:

  • Claude Code: remove the old entry with claude mcp remove roo, then re-run the claude mcp add command from Step 2 with the fresh key.
  • Claude Desktop: Settings → Connectors → Roo → edit the x-api-key value and save.
claude mcp list shows roo as "Failed."

Click the entry (or run claude mcp get roo) to see the error. The two most common causes:

  • Missing or wrong header value — re-add with the correct x-api-key.
  • Older Claude Code version that doesn't speak the Streamable HTTP transport yet. Update with the installer at docs.claude.com/en/docs/claude-code/overview.
My Desktop doesn't show the "Request headers" option under custom connectors.

That field is rolling out gradually. If your account doesn't have it, you have two options:

  • Use the local-install guide instead — a few more steps, but no beta feature required.
  • Switch to Claude Code (terminal) for now, which has supported this since launch.
I don't see my custom domain — my links are on roo.ws.

That's normal — custom domains are opt-in. Ask Claude: "Show me my Roo custom domains." If one shows up as Issued, you can ask for shortlinks on it specifically: "Make a link on l.mydomain.com for https://example.com/promo, slug 'launch'."
